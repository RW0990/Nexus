#Nexus

#Description EJS, CSS and Node.js WebApp for people travelling to help organise travel documents and book events.

#Technologies used Node.js EJS MongoDB CSS Express Render

#How to install Clone Repo in bash/terminal/command line: 
git clone https://github.com/RW0990/Nexus

Download any extra dependencies in bash/terminal/command line: 
npm install

Run in bash/terminal/command line:
npm start or nodemon app.js

Open using Express: http://localhost:3000

Alternatively visit our app live: 
https://nexus-9465.onrender.com
